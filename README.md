# Exact degrees for even Catalan-power Hankel determinants

**Author: Aurantium.** This research note proves the following exact-degree statement.

Let `C(z) = (1-sqrt(1-4z))/(2z)`, `c_m^(2k) = [z^m] C(z)^(2k)`, and `D_(2k,0)(N) = det(c_(u+v)^(2k))_(0<=u,v<N)`, with the empty determinant equal to 1. For all integers `j >= 1`, `k >= 2j-1`, and each offset `r in {j,k+1-j}`, there is a polynomial `F_(k,r) in Q[n]` such that

```text
F_(k,r)(n) = (-1)^(n*binom(k,2)) D_(2k,0)(kn+r)  for every integer n >= 0,
degree F_(k,r) = (2j-1)(k-j).
```

The coefficients are rational; the values at the specified nonnegative integer arguments are integers. The word *offset* permits `r=k` when `j=1`, so the matrix size is `kn+k`. The two offsets coincide when `k=2j-1`. The boundary `k=j=1` has degree zero. For `j=3`, the result gives both offsets `3` and `k-2` for every `k>=5`, with degree `5(k-3)`.

The moment shift is exactly zero and the Catalan power is even. No conclusion is asserted here for arbitrary shifts, odd Catalan powers, Narayana-parameter deformations, or all related conjectures. The argument establishes an exact degree, rather than only a bound or an interpolation pattern. Read the complete proof, including the general theorem, in the [10-page PDF](main.pdf). The editable [main.tex](main.tex) is a standalone LaTeX document with inline references.

The proof uses a finite determinant reduction and quotient minors. A positive moment determinant rules out cancellation of the highest-degree term. Classical determinant identities, the original question, and previously known parameter ranges remain attributed in the manuscript and [REFERENCES.md](REFERENCES.md). No worldwide-priority or independent human peer-review claim is made.

## Reproduce the exact finite checks

Use **Python 3.10 or newer**, with its standard library only. Keep assertions enabled; do not use `python -O`. In this directory run:

```sh
python verify_cigler.py
```

The program recomputes its suite and compares the resulting exact structures with `exact_checks.json` and `exact_polynomials.json`. It also checks the SHA256 of `k16_certificate.json` before comparing its values and Newton coefficients. The expected final summary from the included records is:

```json
{
  "all_checks_passed": true,
  "symbolic_j3_polynomials": 23,
  "direct_hankel": 60,
  "remainder_determinants": 429,
  "general_j_quotient": 267,
  "k16_values": 452,
  "empty_hankel": 1
}
```

The full suite was not rerun for this edition; these are the stored outputs and expected counts. Their finite coverage is:

- 23 residue-three symbolic polynomials: `k=5,...,24,32,40,50`.
- 60 direct Hankel comparisons: `k=5,...,12`, `n=0,...,3`, both distinct offsets.
- 429 remainder comparisons: `k=5,...,24`, `n=-4,...,6`, both distinct offsets. Negative indices refer to the algebraic remainder extension, never negative-size Hankel determinants.
- 267 general-j quotient comparisons: `k=2,...,18`, `1<=j<=floor((k+1)/2)`, `n=0,1,2`, together with finite positive moment-determinant checks.
- 452 supplementary `k=16` values and both Newton coefficient lists; the empty determinant convention is also checked.

The general-j numerical checks do not constitute an all-j symbolic degree verification. The full theorem follows from the proof, not from these finite checks. `exact_polynomials.json` stores exact rational coefficients in powers of **`n+1`**, not powers of `n`. All necessary files are included; the verifier needs no prior archive, network access, third-party Python package, or external data directory.

To regenerate the two output JSON files, use `python verify_cigler.py --write-data`. This overwrites those files, so work in a copy if you want to retain the supplied records. The certificate is an input to this comparison and is not regenerated by that option. A standard LaTeX installation can build `main.tex`; the source has no external figures or bibliography files.
